Download

Every version is published on GitHub Releases, with the SHA-256 of each file next to it. The installers are under 15 MB.

macOS

macOS 11 or later, Apple silicon or Intel

  • …_universal.dmg — Open it and drag Quran Reader to Applications.

Signed and notarized by Apple.

Windows

Windows 10 or 11 (64-bit)

  • …_x64-setup.exe — Installs for your user account, no administrator rights needed.
  • …_x64_en-US.msi — For administrators who deploy software.

Not yet signed with a Windows certificate, so SmartScreen may ask once: “More info” → “Run anyway”.

Linux

x86-64; uses the system's WebKitGTK 4.1 (except the AppImage)

  • …_amd64.AppImage — Runs anywhere and updates itself.
  • …_amd64.deb — Debian, Ubuntu 22.04 or later.
  • …x86_64.rpm — Fedora, openSUSE.

The .deb and .rpm are updated by downloading the new package.

Updates

The app asks GitHub Releases for a new version when it starts and offers to install it; it never installs without your click. Updates are signed, and the app refuses one whose signature does not match the project's key. You can turn the check off in the settings (Aa).
