# Contributing

Thanks for helping. A few rules keep the project fast and trustworthy.

## Text accuracy comes first

- Never edit Quran text by hand. The displayed text is generated by `cargo xtask` from pinned, checksummed sources.
- If you spot a rendering or text problem, open an issue with the reference (e.g. `2:255`), OS and a screenshot.

## Licensing

- Code contributions are MIT.
- New data (translations, tafsir, audio timings) or fonts need a clear, redistributable license. Add an entry to `LICENSES/README.md` with source URL, license and SHA-256 in the same PR.
- When in doubt, build it as a user import instead of bundling it.

## Workflow

```bash
pnpm install
pnpm lint typecheck test build
cargo fmt --all
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

- Keep PRs small and focused.
- Record non-obvious design decisions in `DECISIONS.md`.
- Performance-sensitive code in `quran-core` should come with a benchmark.
